JANTEX REGISTER SCANNER — ابتدائی مکمل پروجیکٹ

ضروری چیز:
- Windows کمپیوٹر یا ایسا ہوسٹنگ سرور جس پر Node.js چل سکے۔
- AI Extraction کے لیے OpenAI API Key۔ یہ ایپ کے اندر سے تصویر بھیجتی ہے؛ کسی دوسری موبائل ایپ میں تصویر کھولنے کی ضرورت نہیں۔
- انٹرنیٹ درکار ہے۔ API استعمال کرنے کے چارجز الگ ہو سکتے ہیں۔

چلانے کا طریقہ (Windows):
1) Node.js LTS انسٹال کریں: https://nodejs.org
2) اس فولڈر میں Terminal/CMD کھولیں۔
3) `npm install` چلائیں۔
4) `.env.example` کی کاپی بنا کر نام `.env` رکھیں۔
5) `.env` میں OPENAI_API_KEY کے سامنے اپنی API key درج کریں۔
6) `npm start` چلائیں۔
7) براؤزر میں http://localhost:3000 کھولیں۔

اہم:
- ڈیٹا data/jantex.sqlite میں محفوظ ہوتا ہے۔
- اصل تصاویر uploads فولڈر میں محفوظ ہوتی ہیں۔
- Download Master Excel سے موجودہ تمام ریکارڈ Excel میں ملیں گے۔
- پروجیکٹ کو آن لائن استعمال کرنے کے لیے HTTPS ہوسٹنگ اور سرور درکار ہوگا۔
- API Key کسی کے ساتھ شیئر نہ کریں اور public frontend میں ہرگز نہ رکھیں۔
- یہ پہلا قابلِ آزمائش ورژن ہے؛ اپنے اصل رجسٹر کی تصاویر سے لازماً ٹیسٹ کریں۔
